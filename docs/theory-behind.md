# Theory Behind the Ranking

## Why Pairwise?
Humans are notoriously bad at absolute estimation (e.g., "This task is a 7/10"). We are much better at relative comparison (e.g., "Task A is harder than Task B"). Pairwise comparison leverages this strength to build a robust ranking.

## Bayesian Ranking (TrueSkill / Bradley-Terry)
This system uses a probabilistic model inspired by **TrueSkill** and the **Bradley-Terry model**.

### The Model
Each item $i$ has a hidden "skill" or "value" parameter $\mu_i$ and an uncertainty $\sigma_i$.
- $\mu$ (Mu): The estimated mean value of the item.
- $\sigma$ (Sigma): The system's uncertainty about that value.

When Item A "beats" Item B in a comparison:
1.  The system increases $\mu_A$ and decreases $\mu_B$.
2.  The system decreases $\sigma_A$ and $\sigma_B$ (it becomes more confident).

### Gaussian Distribution
We model the skill of each item as a Gaussian distribution $N(\mu, \sigma^2)$. The probability that Item A beats Item B is calculated based on the overlap of their distributions.

## Active Learning (Uncertainty Sampling)
A naive pairwise approach requires comparing every item with every other item ($O(n^2)$), which is impractical for large lists.

This system uses **Active Learning** to select the "most informative" pair to compare next.
It looks for pairs that:
1.  **Have high uncertainty** (large $\sigma$).
2.  **Are close in rank** (similar $\mu$).

By focusing on these pairs, the system converges to a stable ranking much faster, often requiring only $O(n \log n)$ comparisons.

## Kendall Tau Coefficient
To measure how "stable" or "certain" the ranking is, we use the **Kendall Tau rank correlation coefficient**.
- We compare the current ranking (based on $\mu$) with a ranking generated by sampling from the posterior distributions.
- A value close to **1.0** indicates high certainty (the ranking is unlikely to change significantly with more votes).
